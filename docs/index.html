KRA eTIMS error codes

TaxID embeds fiscal operations in existing invoicing, POS and ERP software. This reference covers raw control-unit codes, not TaxID transaction statuses. A signed receipt does not establish central KRA acceptance.

OSCU/VSCU resultCd reference, including reported codes outside the cited KRA specification.

Multiple success-code variants exist KRA returns "000" (OSCU spec §4.18, also confirmed live from the VSDC 2.0.6 JAR), "0000" (observed live from GavaConnect), and "00" has been reported for the VSCU JAR. Never hardcode a single string. Always check membership in {"0", "00", "000", "0000"}.
