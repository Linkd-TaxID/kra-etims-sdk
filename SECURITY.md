# Security policy

[Report a vulnerability privately on GitHub](https://github.com/Linkd-TaxID/kra-etims-sdk/security/advisories/new). Use that form for security issues in the Python SDK, its documentation, or its distribution.

Include the installed `taxid-etims` version, the affected component, the observed impact, and steps to reproduce it safely. Redact credentials, device keys, taxpayer identifiers, and personal data. Keep report details out of public issues and pull requests.
